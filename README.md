# Blurr: for WhatsApp Web

Share your screen, not your chats. Blurr blurs messages, chat previews, names, profile pictures and media on WhatsApp Web, with hover to reveal one item.

- **Presentation mode (Alt+P):** hides the whole chat list before a screen share.
- **On or off (Alt+B).**
- **Health lights:** green when each part is hidden, a warning if WhatsApp changes its page. If a part cannot be found, Blurr blurs its whole area, so it never fails open.
- **Private by design:** no internet, no data collected, `storage` permission only.

## Install for development
1. Open `chrome://extensions` and turn on Developer mode.
2. Click "Load unpacked" and choose this folder.
